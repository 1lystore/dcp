# DCP Python

Use the vault CLI and `@dcprotocol/agent` for the current developer path.

For real testing today, use:

```bash
npm install -g @dcprotocol/vault @dcprotocol/agent
dcp init
dcp-agent run --mode mcp --agent claude_desktop
```

This folder is kept out of the public quickstart until the Python package matches the current vault and agent flows.
